Privacy Policy

Application: Italo Jewelry Combiner
Developer: LuckyCat
Last updated: November 8, 2026

Scope

Italo Jewelry Combiner is a private desktop application used by its account owner to prepare jewelry product images and manage content on the owner's Pinterest account.

Information processed

  • Pinterest authorization token: The application uses an OAuth access token supplied by the account owner to make authorized requests to Pinterest. On Windows, the application stores this token using the operating system credential store through the Python keyring library.
  • Pinterest account and board information: The application requests the authenticated account information and the list of boards so the owner can choose a destination board.
  • Pin content: Product images, Pin titles, descriptions, alt text, and destination links are stored locally in the application's files and database.
  • Product feed data: The application processes product image URLs and affiliate destination URLs supplied by the account owner.

How information is used

Information is used only to prepare product collages, organize a local publication queue, display the owner's Pinterest boards, and create a Pin when the owner explicitly confirms publication. Local image files are encoded and sent to Pinterest as part of the Pin creation request. The application does not intentionally send the account owner's Pinterest data to any separate analytics or advertising service.

Storage and sharing

Product data, generated images, and the publication queue are stored locally on the owner's computer. The application does not operate a separate cloud database or provide data to other users. Information submitted to Pinterest is handled by Pinterest under its own privacy policy and terms.

Retention and deletion

The account owner can delete local application data and generated files from the computer. The owner can revoke the application's access through Pinterest account settings. Removing the local token does not itself revoke a token already issued by Pinterest; revocation should be completed through Pinterest.

Security

The application is intended for use on the account owner's computer. The owner should protect their Windows account and must not share OAuth tokens or application credentials. No software can guarantee absolute security.

Children

This application is not designed for children and is not directed to children.

Changes and contact

This policy may be updated if the application's data practices change. For privacy questions, contact the application operator through the GitHub profile associated with the username s9370018688-bit.
